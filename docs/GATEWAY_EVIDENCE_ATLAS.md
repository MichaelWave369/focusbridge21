# Gateway Evidence Atlas and Future-Target Lab (F01)

FocusBridge21 contains an independent, original educational atlas examining the 1983 US Army analysis of the Monroe Gateway Process. Gateway was assessed for intelligence purposes; it did not experimentally establish remote viewing or consciousness traveling through time.

## Eight evidence topics

The live atlas reviews provenance, Focus-level terminology, binaural beats, 7 Hz/Schumann resonance, altered body location, holographic/Absolute metaphysics, Focus 15/21 time claims, and the distinct STARGATE program. Each expandable item separates the historical claim from currently supported observations and limitations.

## F01: prediction BEFORE target

The existing Chapter 3 Blind Target Lab selects its hidden target before each prediction. F01 is **separate**, chooses one of four symbols before a *subsequent* random draw, and records 20 trials with all feedback delayed until completion. The cryptographically secure browser RNG is mandatory. No camera, microphone, personal data, audio stimulation or QMM prerequisite is needed.

A completed block receives its own gateway_future_target_lab receipt in the existing local Signal Ledger, recording the full guesses and targets. It does not change older tele_target_lab receipts, sound recipes or other storage. The user can inspect or alter browser state; results are not tamper-proof or externally verified. Incomplete blocks are discarded.

Under the chance-only model the expected score is five matches out of twenty. The one-sided Binomial(20, 0.25) chance tail is displayed as an educational descriptive statistic, not a significance claim. Repeated blocks, optional stopping, selection bias, and an editable local browser invalidate scientific precognition conclusions.

A rigorous successor would pre-register hypotheses, sample size, exclusions and analysis; use immutable independent timestamped prediction commitments before external randomness; independently blind scorers; report all attempts and replicate.

## Ethics and privacy

No supernatural, medical or mental-health effects are promised. Exercises are voluntary, do not involve forced breathing or sleep restriction, and should be stopped if uncomfortable. The Signal Ledger is browser-local, unencrypted and editable. This module contains no Monroe Institute audio, scripts or proprietary Hemi-Sync material.
