Future Beacon Protocol.

Make 20 predictions now. Commit their hash to a public timestamped GitHub comment before a future drand Quicknet round arrives. Then audit the sealed predictions against the public randomness, with strict checks for late or edited records.

What this is: an educational, auditable probability experiment. It does not demonstrate precognition or time travel. The app does not independently validate drand BLS signatures, and public GitHub comments are required for the stronger online audit.

Public commitment procedure

  1. Complete all 20 symbol predictions. Do not reveal your private sealed plan publicly.
  2. Download and safely retain the private sealed JSON. Only its commitment hash belongs in the public comment.
  3. Before the displayed UTC deadline, post the exact witness line as a comment on a public GitHub issue. Avoid editing it afterward.
  4. After the target round is published, paste the public comment URL and choose Verify public records, or run the independently usable Node CLI against your saved JSON.

The witness must have been created and last edited at least 30 seconds before the scheduled beacon round. The generated round is approximately six minutes in the future, providing time to post.
