How to register

  1. Enter 20 predictions in each of four blocks and download the private sealed JSON.
  2. Post ONLY the resulting public witness line as a comment on a public GitHub issue before the stated UTC deadline. Do not edit it afterward.
  3. Once all four beacon rounds have passed, follow the F03 audit instructions to run the local BLS verifier and produce a full results report.
  4. Report all four blocks, including failures. No deleting inconvenient outcomes.

Local files contain random nonces and predictions; they are not automatically uploaded. Posting the commitment publicly identifies a GitHub account, so use a research-specific account if privacy matters.
