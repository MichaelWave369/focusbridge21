GATEWAY RESEARCH / F04

Open Cohort Study.

One preregistered schedule, multiple voluntary participants, and an independently auditable record. Every participant predicts against the same four future beacon rounds so no one can quietly swap a favorable schedule into the study.

Research boundaries: This is pilot study infrastructure, not evidence of precognition or a clinical trial. Public GitHub comments reveal account names. Do not collect real names, health histories, or other sensitive information. Formal human-subject research needs appropriate independent ethics review.

Enrollment and verification rules

  1. The study organizer publicly posts the exact study registration line on a dedicated public GitHub issue before admitting anyone.
  2. Each participant loads the same public study JSON, chooses 80 predictions, privately saves the sealed campaign, and posts both generated witness lines as one GitHub comment on that issue before its enrollment cutoff.
  3. The first qualifying, distinct GitHub accounts up to the fixed cohort size make up the sample. Extra, invalid and late registrations remain visible.
  4. After the future rounds, the organizer independently verifies each registered participant's sealed file against the original comments and pinned-key BLS signatures. Missing results are reported, never silently dropped.

The primary chance-model analysis is available only for a full, verified cohort. Because participants share target rounds, F04 uses an exact shared-target null distribution rather than treating every human prediction as independent.
